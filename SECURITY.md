# Security Policy

## Reporting a Vulnerability

Do not open a public issue to report security problems.

Report vulnerabilities privately using GitHub private vulnerability reporting
(Repository > Security > Report a vulnerability). You will receive an
acknowledgment and we will coordinate a fix before details are disclosed.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | Supported |

## Responsible Disclosure

Please allow a reasonable time to prepare and ship a fix before publishing
details.
